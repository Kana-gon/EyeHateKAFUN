# タイトル
Eye Hate Kafun
制作期間：2025.5 (一週間ゲームジャム お題「あい」参加作品)
## 概要
目になって、涙弾を撃って花粉を蹴散らす見下ろし型シューティングゲームです。
以下のデモURLからプレイ可能です。

Unity (C#)
## 目的
-	「短時間で遊ばれるゲームジャム作品」である事を意識し、触った瞬間に理解できて、すぐ楽しめるゲームを作ることを目的としました。プレイヤーが深く考えなくても遊べるよう、操作の気持ちよさや実際の見た目から直感的に理解できる構造を重視しています。そのため、ゲームのテーマである「目」と、ゲームシステムや操作と自然に結び付け、「理解コストに対する楽しさ」を最大化する事をひとつの軸としました。
-	「短期間で制作するゲームジャム作品」である事も考慮し、制作スケジュール管理や、企画の取捨選択についても注意を払いました。新しい技術を無理に採用するのではなく、自分が確実に扱える技術を基盤にしながら、限られた時間で完成度を高めることを意識しています。これは、「制作コストに対する楽しさ」の最大化というもうひとつの軸に繋がっています。
-	Unity の基礎を『CardsAndYou』開発を通して習得済みであったため、本作では新たな技術習得よりも、既に身につけた技術を活かして楽しさを最大化することを主要な目的にしています。
## 工夫した点
-	モチーフとメカニクスの一致
    - ゲーム的な仕様を、テーマである「目」の動作や現象に落とし込むことで、モチーフとメカニクスの一致によってルール説明をしなくても自然に理解できる構造を目指しました。
結果として、UI 表示に頼らずとも状況が伝わるデザインの成立と、それによる工数の削減 (=制作コストに対する楽しさの増加)にも繋がりました。
    - 例：
        - 「ガード中は弾が出ない」→「目をつぶると涙は出ない」
        - 「一定ダメージでスタンし、一定時間で回復」→「花粉に当たりすぎると涙目になって強く閉じ、一定時間で目を開ける」
        - 残弾数→目の潤い、ダメージ→充血度などUIの代替
-	操作感を高める実装の徹底
DOTweenによる瞳の滑らかな追従
弾発射時、まばたき時等の音声再生タイミングの微調整と音声素材の厳選
-	プレイヤー(目)のアニメーション・状態遷移の、ステートマシーンを使っての管理
-	イベントフラグによるウェーブ進行の管理と、それを応用したボス再戦機能
-	ボスのフェーズごとの攻撃パターンに、道中で使用した雑魚敵の挙動を再利用しました。既存の行動ロジックを組み合わせることで、複雑な新規実装を増やさずに変化のあるボス戦を構築できました。これは、一週間という短期開発の中で、制作コストを抑えながらゲーム体験の厚みを確保することを意図したものです。
## 困難だった点と対応
-	一週間という厳しい時間的制約
    - 先述の通り「理解コスト」「実装コスト」の2つの観点を重視して取捨選択を行い、主にゲームのコア部分の完成度を高める方向に集中しました。
-	UIの削減によって、状況が伝わるかの見当を付けるのが難しくなった。
    - 友人にテストプレイしてもらい、そこでの意見を反映して更新しました。（残り弾数が見辛い→目のうるおいを表す線を太くする、一定時間で消えるチュートリアルが読み切れない→チュートリアルが表示される状況を細分化し、一文一文を短くする）
